He creado una plantilla de formulario personalizada con CSS para adaptar colores, sombras y tipografías.

### ¿Cómo usarlo con n8n?
1. En tu flujo de n8n, reemplaza el nodo **Form Trigger** por el nodo **Webhook Trigger**.
2. Configura el método del Webhook en `POST`.
3. Copia la URL del Webhook que te genera n8n y pégala en el atributo `action="..."` del código HTML.
4. ¡Listo! Puedes alojar este HTML en cualquier servidor, GitHub Pages o integrarlo en tu sitio web.
